# G-Calls S.A.S. - Portal Web Corporativo
Este proyecto es una plataforma web moderna desarrollada para G-Calls S.A.S., enfocada en la gestión sostenible y soluciones integrales en cadena de abastecimiento, seguridad y salud ocupacional.

## 🚀 Tecnologías Utilizadas
Frontend: React.js con Vite para una experiencia de desarrollo ultrarrápida.

Estilos: Tailwind CSS para un diseño responsivo y moderno.

Componentes: Radix UI y Lucide React para una interfaz accesible y minimalista.

Diseño UI/UX: Prototipado previo enfocado en la experiencia del usuario y arquitectura de información.

🛠️ Estructura del Proyecto
/src/components: Componentes reutilizables (Navbar, Footer, Layout).

/src/assets: Recursos visuales, logotipos e iconografía corporativa.

/src/pages: Vistas principales del portal.

⚙️ Instalación y Uso

1. Clonar el repositorio:
```Bash

git clone https://github.com/tu-usuario/gcalls-web-portal.git

```
2. Instalar dependencias:
```Bash

npm install

```

3. Iniciar el entorno de desarrollo:
```Bash

npm run dev

```
